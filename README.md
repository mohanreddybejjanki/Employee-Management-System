# 🚀 Employee Management System (EMS)

A full-stack Employee Management System built with Spring Boot, designed to manage the complete employee lifecycle with secure authentication and real-world business features.

---

## 📌 Overview

This application allows organizations to manage employees, attendance, leaves, and salary operations efficiently.

It follows a scalable layered architecture:

Controller → Service → Repository → Entity

---

## 🛠 Tech Stack

### Backend
- Java 17
- Spring Boot 3
- Spring Security + JWT
- Spring Data JPA (Hibernate)
- Maven

### Database
- MySQL 8

### Frontend
- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 🔐 Features

### Authentication & Security
- JWT-based authentication (stateless)
- Role-based access control (ADMIN, EMPLOYEE)
- BCrypt password encryption

### Employee Management
- Add, update, delete employees
- Search, filter, sort
- Pagination support
- Profile photo upload

### Leave Management
- Apply for leave
- Approve / reject requests
- Auto leave balance tracking

### Attendance System
- Daily check-in / check-out
- Late detection
- Attendance history
